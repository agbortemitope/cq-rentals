# CQ Rentals

## Project Overview
CQ Rentals is a project designed to manage rental services efficiently. This repository contains the source code and configuration files for the application.

## Run locally

Requires Node.js.

```bash
npm install
npm run dev
```

Vite serves the site on port 5000. Build the static site with `npm run build`; the output goes to `dist/`.

## Deployment

`netlify.toml` contains Netlify build and publish settings. The repository also has a GitHub Actions workflow for GitHub Pages. These files do not confirm whether a Netlify site is linked to the repository in the Netlify dashboard.

Public phone, email, Instagram, and booking-form recipient details are in `contact.json`.
